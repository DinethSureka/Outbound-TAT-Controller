TAT logic

Status bands

Where the remaining time before the expected packing stamp turns from one status into the next.

Out of TAT as one block at the foot
Sorted by remaining time the list leads with whatever breaches next and sends anything already breached to the bottom, collected under one summary line. Click that line to open it to document level.
Fill each row by time used
The row fills left to right as its TAT is spent, so how far through an OBD is reads without checking the numbers. Solid at out of TAT.

Ambient glow

Statuses on the board
Leave a status off and it disappears from the whole board — tiles, ring, list, breakdown and histogram. At least one stays on.
The list leads with whatever breaches next; anything already out of TAT drops to the foot. The header also carries a live countdown to the next document due, and the workload panel keeps a rolling trend for as long as the board stays open.

Rules

Read top to bottom — the first rule a document matches sets both its TAT and where its clock starts. An empty match box means “any”. Use commas for several values.

Cut-off codes

How the weekday codes in the store master translate into a time of day.

A weekday cell may hold more than one code (C1,C3) — the earliest one the document still makes is used. A cell holding a plain time such as 09:00 works too. Blank means the store takes no cut-off that day, so the clock rolls to the next day that does.

Completion

Start fresh on every upload
A new extract carries its own picking statuses, so hand marks made against the previous one are stale. Clearing them, along with the filters, means nothing left over from the last file can be read as current. The upload notice offers one click to put the marks back.
Marks are kept in this browser against the document number, so they survive a refresh. With the switch above off they also survive a re-upload.

Store master

Cut-off calendar

One row per site. A weekday cell holds the cut-off code that store takes that day — C1, C3, or a plain time such as 09:00. Leave a day empty and the store takes no order then, so a document released that day rolls forward to the next day it does: a site carrying only Wed C3 puts a Sunday release on Wednesday 19:00. Codes become times under TAT logic › Cut-off codes.

Every edit is kept on this browser straight away and survives a refresh, an orders upload and a new release of the board — the master only has to be loaded once. Export JSON hands the same master to another screen. The Cut-off column is the site's own fallback time, used on a day that is open but carries a code the table cannot read.

Settings

Out-of-TAT alert

A tone when a document that has not been marked complete crosses into out of TAT. It only sounds while this board is open, and a browser needs one click on the page before it allows any sound at all — switching the alert on counts as that click.

Alert on
The same switch as the bell in the header.

Tone

A warehouse floor is loud, and a tone people learn to ignore is worse than none. Pick one for each level and listen to it here before you rely on it — a breach plays its tone twice, a warning once.

The warning tone is only used when the alert above is set to sound at the first warning band as well.

Volume

Sets the level for every tone this board plays. The machine's own volume still applies on top of it.

Mute 70%
Muting leaves the alert switched on, so the toasts and the board still react to a breach — only the sound stops.
